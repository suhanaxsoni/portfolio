# Suhana Soni — Internship Portfolio

This is a recruiter-focused single-page portfolio for internship applications.

## Before publishing
Replace these placeholders in `index.html`:
- `YOUR_EMAIL@example.com`
- `https://www.linkedin.com/in/YOUR-LINKEDIN/`
- `https://github.com/YOUR-GITHUB`

## Important accuracy note
The portfolio deliberately describes projects and experience conservatively based on the information available. Add exact internship/company names, dates, GitHub links, demos, metrics, and certifications only where you can verify them.

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.
